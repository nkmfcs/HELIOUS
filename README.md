# HELIOUS

Склад и касса детских чешек. Белые / чёрные / серые / золотые, размеры 14–28, учёт по 5 пар.

- Склад, коробки #1–#5, приход
- Клиенты и заказы отдельно
- Касса, долги, работники
- Предзаказ если меньше 30 пар
- Облако: автоматическое сохранение и проверка изменений каждые 30 секунд в открытой вкладке, при возврате в приложение и восстановлении сети. Ручной выбор нужен только при независимых изменениях обеих версий или неизвестной истории непустой локальной копии.

Живое приложение: [uzcheska.grok.me](https://uzcheska.grok.me)

```bash
npm install
npm run dev
```
